# 인천국제공항공사 여객편 주간 운항 현황 (공공데이터) 안내

> 출처: [공공데이터포털 「인천국제공항공사_여객편 주간 운항 현황」](https://www.data.go.kr/data/15095074/openapi.do)
> 수집일: 2026-10-22 · 구분: 공식(인천국제공항공사 제공, 이용 허락 범위 제한 없음)

## 이 서비스에서 어떻게 쓰는가
- 이용자가 말한 항공편 번호(예: KE703)를 이 자료에서 찾아, **출발 예정 시각**과 **터미널**을 보여 줍니다.
- 찾지 못하면 번호 형식(영문 2자리 + 숫자 1~4자리)만 확인하고, 출발 시각을 이용자에게 직접 묻습니다.
- 자료에 있다고 해서 탑승이 보장되는 것은 아닙니다. 지연·결항은 항공사 안내를 따릅니다.

## 자료의 범위
- 인천공항 여객기의 출발·도착 운항 정보입니다.
- **조회일 기준 오늘(D+0)부터 6일 뒤(D+6)까지**의 예정만 있습니다. 과거 기록은 없습니다.
  → 그래서 홈드롭 시연 예약도 6일 이내 출발편만 받습니다.
- 동계·하계 시즌이 바뀌는 시기(동계 10월 3주차 이후, 하계 3월 3주차 이후)에는 D+6 자료가 빠질 수 있습니다.
- 갱신 주기는 실시간(키워드상 3분)입니다.

## 주요 항목
| 항목 | 뜻 |
|---|---|
| airline | 항공사 이름 |
| flightId | 항공 편명 (예: KE703) |
| scheduleDateTime | 예정 시각 (예: 202610221010 → 2026-10-22 10:10, 한국 시간) |
| estimatedDateTime | 변경된 시각 |
| airport | 도착지 공항 이름 |
| terminalid | 터미널 구분 — P01 제1터미널, P02 탑승동, P03 제2터미널 |
| chkinrange | 체크인 카운터 |
| gatenumber | 탑승구 |
| remark | 운항 상태 (출발, 결항, 지연 등) |
| codeshare / masterflightid | 공동운항 여부와 실제 운항 편명 |

## 호출 한도
- 개발계정 하루 500회. 운영계정은 활용사례 등록 후 하루 10,000회까지 신청할 수 있습니다.
- 이 서비스는 한 번 받은 자료를 10분 동안 재사용해 호출 횟수를 아낍니다.
